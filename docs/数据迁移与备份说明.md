# 数据迁移与备份说明

更新时间：2026-06-03

## 1. 当前数据方式

当前版本使用本地 JSON 数据库：

```text
data/db.json
```

该方式适合 demo、小团队试用和自部署早期版本，不适合高并发多人写入。

## 2. 数据版本

当前数据版本：

```text
schemaVersion = 2
```

服务启动和读取数据时会补齐旧数据缺失字段，并在迁移前生成备份。

## 3. 自动备份

默认备份目录：

```text
data/backups/
```

每次写入数据库前，系统会检查当天是否已有每日备份：

```text
data/backups/YYYY-MM-DD-daily.json
```

如果发生自动迁移，会生成迁移前备份：

```text
data/backups/时间戳-before-migration.json
```

## 4. 自定义备份目录

可在 `.env` 中配置项目外备份目录：

```env
DATA_BACKUP_DIR=/opt/open-sales-assistant-backups
```

生产或长期试用时，建议把备份目录放到项目目录外，避免更新代码时误删。

## 5. 导出和手动备份

后台导出：

```text
GET /api/admin/data/export
```

后台手动备份：

```text
POST /api/admin/data/backup
```

两个接口都要求管理员登录。

## 6. 开源仓库注意事项

不要提交：

- `.env`
- `uploads/`
- `data/backups/`
- 真实客户数据
- API key、token、密码

允许提交：

- `data/db.json` 中的安全 demo 数据
- `.env.example`
- 数据结构和迁移说明

## 7. 恢复数据

1. 停止 Node 服务。
2. 找到目标备份文件。
3. 将备份文件复制为 `data/db.json`。
4. 启动 Node 服务。
5. 系统会自动检查数据版本并补齐字段。

恢复前建议先保存当前 `data/db.json`。
