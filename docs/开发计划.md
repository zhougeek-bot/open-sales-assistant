# 阶段开发计划

更新时间：2026-06-03

## 1. 当前定位

Open Sales Assistant 是一个可自部署的开源团队销售助手 starter kit。当前版本适合个人销售、小团队或试点团队用来搭建销售知识库、客户咨询入口和基础跟进记录。

当前不是商业 SaaS 平台，也不包含托管计费、多组织开通或平台运营后台。

## 2. 当前模块

```text
open-sales-assistant/
  public/             # 前台咨询 + 后台管理页面
  server/             # Express 后端接口
  data/               # 本地 JSON demo 数据
  uploads/            # 上传文件，默认不提交仓库
  docs/               # 项目文档
  package.json
  .env.example
```

## 3. 已完成功能

### 客户咨询端

- 昵称注册、随机密码和登录态记忆。
- 客户资料维护。
- 聊天历史保存。
- AI 基于知识库答复。
- 可附带图片素材。
- 证书查询 demo 流程。

### 后台管理

- 管理员登录与接口鉴权。
- 客户列表、搜索、排序、分页和删除。
- 客户详情、聊天记录、AI 画像和跟进记录。
- 文字、图片、文档素材上传。
- AI 素材分析和待审核建议。
- 知识摘要、销售话术、FAQ、顾虑应对维护。
- 证书新增、删除、批量导入和查询。
- 咨询配置维护。

### 数据与部署

- 本地 JSON 数据库 `data/db.json`。
- `schemaVersion` 数据迁移。
- 每日自动备份和手动备份。
- 数据导出接口。
- PM2、Nginx、宝塔部署参考。

## 4. 下一阶段优先级

### P0：开源可运行版本

- 确保 README、license、贡献指南、安全说明齐全。
- 确保 demo 数据安全、可解释、可替换。
- 增加基础 API 测试和启动验证脚本。
- 增加一键重置 demo 数据脚本。

### P1：团队销售工作台

- 增加销售负责人、跟进状态和下次跟进时间。
- 增加今日待跟进、未回复客户、高意向客户视图。
- 增加客户标签和销售阶段。
- 增加操作日志。

### P2：知识库质量增强

- AI 建议采纳前可编辑。
- 知识库版本历史和回滚。
- 素材搜索、编辑、批量管理。
- AI 用量日志和成本估算。
- Prompt 评测样例。

### P3：自部署增强

- Docker 部署。
- PostgreSQL 或 MySQL 可选数据层，同时保留 JSON 文件存储。
- 数据恢复后台。
- 生产部署 checklist。
- CRM、表单、表格和团队通讯工具连接器示例。

## 5. 开源申请维护重点

- 用 issue 记录路线和缺陷。
- 用 PR 关闭具体功能点。
- 定期 release 和 changelog。
- 用 Codex 辅助 PR review、测试、文档和 release notes。
