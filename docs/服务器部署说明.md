# 服务器部署说明

## 1. 基本信息

应用端口：`3100`

推荐部署目录：

```text
/opt/open-sales-assistant
```

服务器需要 Node.js 20 或更高版本。

## 2. 上传代码

```bash
scp -r open-sales-assistant root@你的服务器IP:/opt/open-sales-assistant
```

如果已有旧版本，先备份：

```bash
mv /opt/open-sales-assistant /opt/open-sales-assistant.bak.$(date +%Y%m%d%H%M%S)
```

## 3. 配置环境变量

```bash
cd /opt/open-sales-assistant
cp .env.example .env
vi .env
```

示例：

```env
PORT=3100
PUBLIC_BASE_URL=https://你的域名
DATA_BACKUP_DIR=/opt/open-sales-assistant-backups
DEMO_LANGUAGE_SWITCH=false

ADMIN_USERNAME=admin
ADMIN_PASSWORD=请设置一个强密码

AI_PROVIDER=kimi
AI_BASE_URL=https://api.moonshot.cn/v1
AI_API_KEY=请替换为你自己的 API Key
AI_TEXT_MODEL=kimi-k2.6
AI_VISION_MODEL=kimi-k2.6
```

生产部署必须使用服务器自己的 `.env`。不要把 `.env` 上传到 GitHub，也不要把 API Key 写入 `data/db.json`。

默认界面和 demo 数据都是英文。生产环境建议保持 `DEMO_LANGUAGE_SWITCH=false`，除非该部署明确就是允许重置 demo 数据的公开演示环境。

本项目调用 OpenAI-compatible `/chat/completions` API。可替换为其他兼容服务：

```env
# OpenAI
AI_PROVIDER=openai
AI_BASE_URL=https://api.openai.com/v1
AI_TEXT_MODEL=gpt-4o-mini
AI_VISION_MODEL=gpt-4o-mini

# DeepSeek
AI_PROVIDER=deepseek
AI_BASE_URL=https://api.deepseek.com
AI_TEXT_MODEL=deepseek-chat
AI_VISION_MODEL=deepseek-chat

# DashScope / Tongyi Qianwen
AI_PROVIDER=dashscope
AI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_TEXT_MODEL=qwen-plus
AI_VISION_MODEL=qwen-vl-plus
```

## 4. 安装依赖

```bash
cd /opt/open-sales-assistant
npm install --omit=dev
```

## 5. 使用 PM2 启动

```bash
npm install -g pm2
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup
```

查看状态：

```bash
pm2 status
pm2 logs open-sales-assistant
```

## 6. Nginx 反向代理

```nginx
server {
    listen 80;
    server_name 你的域名;

    client_max_body_size 50m;

    location / {
        proxy_pass http://127.0.0.1:3100;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

检测并重载：

```bash
nginx -t
systemctl reload nginx
```

## 7. 验证

```bash
curl https://你的域名/api/health
```

健康检查只会返回 `aiConfigured` 和模型名，不会返回 API Key。

浏览器访问：

```text
https://你的域名/
https://你的域名/login.html
https://你的域名/admin.html
```

## 8. 数据位置

| 路径 | 用途 |
| --- | --- |
| `/opt/open-sales-assistant/data/db.json` | demo 数据或自部署数据 |
| `/opt/open-sales-assistant/uploads` | 上传文件 |
| `/opt/open-sales-assistant-backups` | 推荐备份目录 |
