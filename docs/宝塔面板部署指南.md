# 宝塔面板部署指南

适用场景：宝塔面板 + Node 项目 + 自有域名。

Open Sales Assistant 不是纯静态站点。它需要 Node.js 服务提供 `/api/*` 接口、上传文件、保存本地数据并调用 AI API。

## 1. 准备目录

推荐服务器目录：

```text
/www/wwwroot/open-sales-assistant
```

## 2. 上传代码

上传 `open-sales-assistant` 项目文件到该目录。

不要上传：

- `.env`
- `node_modules/`
- `uploads/`
- `data/backups/`

如果要保留 demo 数据，可以上传 `data/db.json`。如果是更新线上版本，不要覆盖线上已有 `data/db.json`。

## 3. 安装 Node.js

宝塔面板安装 Node.js 版本管理器，选择 Node.js 20 LTS 或 22 LTS。

## 4. 安装依赖

```bash
cd /www/wwwroot/open-sales-assistant
npm install --omit=dev
```

## 5. 配置 `.env`

```env
PORT=3100
PUBLIC_BASE_URL=https://你的域名
DATA_BACKUP_DIR=/www/backup/open-sales-assistant

ADMIN_USERNAME=admin
ADMIN_PASSWORD=请设置一个强密码

AI_PROVIDER=kimi
AI_BASE_URL=https://api.moonshot.cn/v1
AI_API_KEY=请替换为你自己的 API Key
AI_TEXT_MODEL=kimi-k2.6
AI_VISION_MODEL=kimi-k2.6
```

生产部署必须在服务器 `.env` 中填写自己的 API Key。不要把 `.env` 上传到 GitHub，也不要把 API Key 写入 `data/db.json`。

本项目调用 OpenAI-compatible `/chat/completions` API。可替换为其他兼容服务：

```env
# OpenAI
AI_PROVIDER=openai
AI_BASE_URL=https://api.openai.com/v1
AI_TEXT_MODEL=gpt-4o-mini
AI_VISION_MODEL=gpt-4o-mini

# DeepSeek
AI_PROVIDER=deepseek
AI_BASE_URL=https://api.deepseek.com
AI_TEXT_MODEL=deepseek-chat
AI_VISION_MODEL=deepseek-chat

# DashScope / Tongyi Qianwen
AI_PROVIDER=dashscope
AI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_TEXT_MODEL=qwen-plus
AI_VISION_MODEL=qwen-vl-plus
```

## 6. 创建 Node 项目

宝塔面板进入：

```text
网站 → Node项目 → 添加项目
```

推荐配置：

| 配置项 | 填写 |
| --- | --- |
| 项目名称 | `open-sales-assistant` |
| 项目目录 | `/www/wwwroot/open-sales-assistant` |
| 启动文件 | `server/index.js` |
| 运行用户 | `www` |
| Node版本 | `20.x` 或 `22.x` |
| 端口 | `3100` |
| 启动命令 | `npm start` |
| 包管理器 | `npm` |

## 7. 反向代理

如果域名站点已存在，在站点设置里添加反向代理：

| 配置项 | 填写 |
| --- | --- |
| 代理名称 | `open-sales-assistant` |
| 目标 URL | `http://127.0.0.1:3100` |
| 发送域名 | `$host` |

上传大文件失败时，在 Nginx 配置中增加：

```nginx
client_max_body_size 50m;
```

## 8. 验证

访问：

```text
https://你的域名/api/health
https://你的域名/
https://你的域名/login.html
https://你的域名/admin.html
```

`/api/health` 应返回：

```json
{
  "ok": true,
  "service": "open-sales-assistant"
}
```

健康检查不会返回 API Key。
