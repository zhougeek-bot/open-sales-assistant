# 销售回复 Prompt 评测

仓库提供了一组小型中英文评测数据，用于检查 Demo 销售流程的回复是否与知识库相关、是否避开禁止承诺，以及是否使用预期的回复模式。

## 本地基线评测

运行确定性的本地 fallback 评测：

```bash
npm run eval
```

该命令不使用 AI API Key。它会把中英文 Demo fixture 分别复制到临时目录，启动真实服务，注册临时客户，调用 `/api/chat`，检查回复，然后删除临时数据。

基线评测已加入 `npm test` 和 CI。

## 可选 AI 评测

在 `.env` 中配置自己的 OpenAI-compatible API，然后运行：

```bash
npm run eval:ai
```

该命令使用已配置的服务商和模型，并且不会输出 API Key。AI 输出存在一定波动，失败时需要判断是 Prompt 回归，还是评测短语确实需要经过审核后调整。

## 评测数据

评测用例保存在：

```text
evals/sales-replies.json
```

每组数据包含：

- 英文或中文 Demo fixture。
- 常见销售场景问题。
- 用于检查知识相关性的预期短语。
- 针对包过、保拿证、就业、收入和治疗效果的禁止承诺。

新增用例时只能使用通用 Demo 数据，不能包含真实客户信息。Pull Request 需要说明新增预期短语或安全规则的原因。

## 当前边界

当前是轻量回归测试，不是完整的语义或模型质量 Benchmark。后续可以增加结构化评分、模型对比、评测追踪文件和人工审核样本，同时继续保留无需 API Key 的基线模式。
